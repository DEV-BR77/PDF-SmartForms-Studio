# Datenlebenszyklus

| Daten | Erhebung | Speicherung | Export | Löschung |
|---|---|---|---|---|
| Profile | durch Nutzer/Import | lokal, optional verschlüsselt | ausgewählte Felder | Profil löschen |
| Unterschriften | Bildimport | separater geschützter Bereich | nur explizit | sicher löschen |
| Templates | Import/Designer | lokal | Paket | Template löschen |
| Feldlexikon | bestätigte Zuordnung | lokal | Begriffe ohne Werte | Eintrag/alles löschen |
| Dokumente | Generierung | gewählter Zielordner | Nutzeraktion | Nutzer/Retention |
| Logs | technische Ereignisse | begrenzt, redigiert | Diagnose nach Vorschau | automatisch/manuell |

Einmalfelder werden standardmäßig nicht in Profile übernommen. Netzwerkplugins müssen Ziel, Umfang und Rechts-/Datenschutzkontext sichtbar machen.
