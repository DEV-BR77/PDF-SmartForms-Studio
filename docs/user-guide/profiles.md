# Profile

Profile speichern wiederverwendbare Angaben lokal. Die Verwaltung ist über
**Profile → Profile verwalten** oder `Strg+P` erreichbar.

## Unterstützte Angaben

- Vor- und Nachname der teilnehmenden Person
- Geburtsdatum mit Kalenderauswahl
- Straße, PLZ und Ort
- Telefon und E-Mail
- bis zu zwei erziehungsberechtigte Personen
- frei definierbare Zusatzfelder

Der Nachname des Kindes kann beim Anlegen für eine erziehungsberechtigte Person
übernommen werden. Das gemeinsame Ortsfeld dient auch als Vorschlag für den
Unterschriftsort.

## Löschen und Datenschutz

Das Löschen benötigt eine Bestätigung. Profile werden nicht automatisch in
Austauschpakete übernommen. Laufzeitangaben können verwendet werden, ohne sie
dauerhaft im Profil zu speichern.
