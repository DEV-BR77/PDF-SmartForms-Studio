# Bildunterschriften

Über **Unterschriften → Unterschriften verwalten** können PNG- und JPG-Dateien
für bis zu zwei erziehungsberechtigte Personen hinterlegt werden.

## Empfohlener Import

1. Auf weißem Papier mit dunklem Stift unterschreiben.
2. Foto oder Scan eng zuschneiden.
3. Beim Import optional weißen Hintergrund entfernen und Kontrast verbessern.
4. Ergebnis in der Vorschau kontrollieren.

In der PDF-Vorschau lässt sich die Unterschrift mit der Maus verschieben und
mit dem Mausrad proportional skalieren.

## Wichtiger Hinweis

Eine eingefügte Bildunterschrift ist ein sichtbares Bild. Sie ist weder eine
Zertifikatssignatur noch automatisch eine qualifizierte elektronische Signatur.
Ob sie für einen konkreten Vorgang genügt, muss der Nutzer selbst prüfen.

Unterschriften sind besonders sensible Daten. Sie werden standardmäßig weder
in Austauschpakete noch in Backups aufgenommen.
