# Templates

Ein Template verbindet ein PDF mit Feldpositionen, Feldtypen und Datenquellen.

## Neues Template erstellen

1. **Templates → Neues Template aus PDF** öffnen.
2. Mit der Maus ein Rechteck über einem Eingabebereich aufziehen.
3. Feldtyp und Datenquelle wählen.
4. Pflichtstatus festlegen.
5. Position mit Maus oder Pfeiltasten korrigieren.
6. Template als `.psfstemplate` speichern.

Ein Template-Paket enthält das Grund-PDF, die Zuordnung und Prüfsummen.
Vorhandene Templates werden beim Import nicht ungefragt überschrieben.

## Vertrauensstufen

- **Lokal:** nur auf dem eigenen Computer erstellt.
- **Community:** von Dritten bereitgestellt und vor Verwendung zu prüfen.
- **Verifiziert:** vom Maintainer geprüft.

Fremde Formulare dürfen nur verteilt werden, wenn die erforderlichen Rechte
vorliegen.
