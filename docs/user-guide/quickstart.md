# Erster Start

Auf der Startseite stehen zwei Wege bereit:

- **Eigenes PDF bearbeiten** öffnet ein lokales Formular.
- **Erhaltenes Paket importieren** prüft ein `.psfspackage`, bevor Inhalte
  übernommen werden.

## Eigenes PDF

1. **Eigenes PDF bearbeiten** wählen.
2. PDF auswählen.
3. Erkannte Felder in der farbigen Vorschau prüfen.
4. Fehlende Zuordnungen manuell ergänzen.
5. Optional ein Profil und eine Bildunterschrift verwenden.
6. Speichern, Drucken oder einen E-Mail-Entwurf erzeugen.
7. Die Sicherheitsvorschau vollständig prüfen und bestätigen.

Das Original-PDF wird nicht überschrieben. Die Ausgabe entsteht als
Arbeitskopie.

## Erhaltenes Paket

Beim Import werden Dateitypen, Pfade und Prüfsummen geprüft. Pakete mit
unerlaubten oder manipulierten Inhalten werden blockiert. Ein Austauschprofil
ist absichtlich leer und wird erst auf dem eigenen Computer ausgefüllt.
