# Release-Checkliste

- [ ] Versionsnummer, Build und Commit aktualisiert
- [ ] Feature-Matrix, Roadmap und Changelog aktualisiert
- [ ] Unit-, Integrations-, E2E- und PDF-Regressionstests erfolgreich
- [ ] Architektur-, Security- und Privacy-Gates erfolgreich
- [ ] Neuinstallation, Upgrade, Migration, Backup und Restore getestet
- [ ] Benutzer- und Entwicklerdokumentation aktualisiert
- [ ] Bekannte Probleme und Rollback dokumentiert
- [ ] Build reproduzierbar; SBOM und SHA-256 erzeugt
- [ ] Releaseartefakte geprüft und Freigabe dokumentiert
