# Bekannte Einschränkungen 0.9.0-beta.1

- Unverschlüsselte Backups dürfen nur an einem geschützten Ort gespeichert
  werden. Bildunterschriften sind standardmäßig ausgeschlossen.
- Drucken verwendet derzeit die Windows-Dateizuordnung und den
  Standarddrucker.
- E-Mail wird ausschließlich als lokale `.eml`-Datei vorbereitet; ein Versand
  findet niemals automatisch statt.
- Die heuristische Erkennung flacher PDFs kann Felder übersehen. Offene Felder
  werden in der Sicherheitsvorschau gezählt und müssen geprüft werden.
- Das Plugin-System führt in dieser Version keinerlei Plugin-Code aus.
