# PDF SmartForms Studio 1.0.0-rc.10

RC.10 korrigiert die Bedienprobleme aus dem Praxistest von RC.9.

## Felder bearbeiten

- Erkannte und bereits zugeordnete Rahmen lassen sich direkt verschieben.
- Der rechte untere Rahmengriff ändert Breite und Höhe.
- Ein sichtbarer Löschknopf entfernt eine falsche Erkennung.
- Neue Datenfelder werden über einen gemeinsamen Ablauf entweder dem Profil
  oder nur dem aktuellen Formular zugeordnet.
- Das wiederholte Hinweisfenster vor jedem neuen Rahmen entfällt.

## Unterschriften

- `signature_image` bezeichnet eine sichtbare PNG-/JPG-Unterschrift.
- `digital_signature` bleibt ausschließlich für eine Zertifikats- bzw.
  Acrobat-Signatur reserviert.
- Eine gespeicherte Bildunterschrift kann gezielt in den ausgewählten
  Unterschriftsrahmen eingesetzt werden.
- Der Vorschauknopf in der Unterschriftenverwaltung ist kompakt.

## Templates und Datenquellen

- Die Templateübersicht zeigt das Erstellungsdatum.
- Absender-Name, Absender-E-Mail-Adresse und Absender-Homepage verwenden
  einheitliche Bezeichnungen.
- Veraltete und doppelte Absender-/Empfänger-Einträge werden nicht mehr angeboten.
