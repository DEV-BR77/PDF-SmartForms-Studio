# Datenschutzprüfung 1.0.0-rc.1

- Verarbeitung erfolgt standardmäßig lokal.
- Es gibt keine Telemetrie, Werbung oder Benutzerkonten.
- Profile und Unterschriften werden nicht automatisch weitergegeben.
- Austauschpakete enthalten ein bewusst leeres Profil.
- Bildunterschriften sind in Backups standardmäßig ausgeschlossen.
- Logs enthalten keine Dokumentinhalte oder Profilwerte.
- Empfänger und Anhänge müssen vor einem E-Mail-Entwurf bestätigt werden.
- Netzwerkfunktionen sind im Kern nicht aktiv.

Die Software ist ein Werkzeug. Rechtsgrundlage, Aufbewahrungsdauer,
Empfängerauswahl und Zulässigkeit der konkreten Verarbeitung bleiben in der
Verantwortung des Nutzers beziehungsweise der einsetzenden Organisation.
