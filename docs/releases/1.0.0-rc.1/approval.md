# Freigabeentscheidung 1.0.0-rc.1

## Technische Freigabe

Status: **lokal freigegeben als privater Release Candidate**.

Formatierung, Lint, strikte Typprüfung, 53 automatisierte Tests,
UI-Smoke-Test, Windows-Build, SBOM und Prüfsummenprüfung waren erfolgreich.
Die GitHub-CI muss denselben Stand nach dem Push bestätigen.

## Öffentliche Stable-Freigabe

Status: **nicht freigegeben**.

Blockierende organisatorische Punkte:

1. endgültigen Source-Available-Lizenztext juristisch prüfen
2. gewerbliche Lizenzbedingungen separat festlegen
3. Windows-Codesignatur beschaffen oder den Umgang ohne Codesignatur
   ausdrücklich beschließen
4. Release Candidate durch reale Nutzer mit neutralen Testdaten prüfen

Der private RC darf für Entwicklung und interne Tests verwendet werden.
