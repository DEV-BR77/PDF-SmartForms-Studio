# PDF SmartForms Studio 1.0.0-rc.3

Dieser private Release Candidate korrigiert das Analysefenster nochmals gezielt.

## Änderungen

- Das Analysefenster besitzt ausdrücklich Minimieren- und Maximieren-Schaltflächen.
- Die vollständige PDF-Seite wird beim Öffnen und nach jeder Größenänderung eingepasst.
- Die Schaltfläche „Seite“ stellt die automatische Anpassung nach manuellem Zoom wieder her.
- Ein falsch erkannter Vorschlag kann über „Erkennung entfernen“ aus der aktuellen
  Dokumentanalyse gelöscht werden.
- Die Titelleiste der Analyse zeigt die laufende Versionsnummer, damit alte und neue
  EXE-Dateien eindeutig unterschieden werden können.

## Bedienung: Falsche Erkennung entfernen

1. Den falschen Eintrag rechts unter „Erkannte Felder“ auswählen.
2. „Erkennung entfernen“ anklicken.
3. Die Rückfrage bestätigen.

Die Erkennung wird nur aus der aktuellen Analyse entfernt. Beim erneuten Öffnen wird
das PDF neu analysiert.
