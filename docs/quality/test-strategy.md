# Teststrategie

- Unit-Tests für Domänenregeln, Validierung, Koordinaten und Matching
- Komponententests für Profile, Templates, Lexikon, Signaturen und Backups
- Integrationstests für Profil → Mapping → PDF → Export
- End-to-End-Tests für Import, Analyse, Ergänzung, Signatur und Ausgabe
- PDF-Regressionstests mit selbst erstellten Golden Masters
- Security-Tests für Pakete, Pfade, Rechte, Signaturen und Updates
- Privacy-Tests für Logs, Exporte, temporäre Dateien und Löschung
- Migrationstests für jedes unterstützte Schema
- UI-, Tastatur-, High-DPI- und Barrierefreiheitstests

Stable benötigt null offene P0/P1-Fehler.
