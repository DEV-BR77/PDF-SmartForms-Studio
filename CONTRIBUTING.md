# Mitwirken

Dieses Projekt folgt dem `BR-Development-Framework`.

1. Vor größeren Änderungen Issue/Epic referenzieren.
2. Keine echten Namen, Formulare, Unterschriften, Adressen oder Gesundheitsdaten einreichen.
3. Branches: `feature/PSFS-123-kurzbeschreibung`, `fix/...`, `docs/...`.
4. Python: Type Hints, Ruff, Black, pytest; Domänenlogik ohne UI-Abhängigkeit.
5. Nutzerrelevante Änderungen aktualisieren Dokumentation und Changelog.
6. Pull Requests nennen Akzeptanzkriterien, Tests, Datenschutz-/Sicherheitsauswirkung und Screenshots bei UI-Änderungen.

## Definition of Done

- Akzeptanzkriterien erfüllt
- passende automatisierte Tests
- Lint/Typen/Architekturprüfungen grün
- Dokumentation und Changelog aktuell
- keine personenbezogenen Testdaten
- Security/Privacy geprüft
- Review abgeschlossen
