# Mitgelieferte Vorlagen

Geprüfte `.psfstemplate`-Pakete aus dem Repository
`DEV-BR77/PDF-SmartForms-Templates` werden vor einem Release in diesem Ordner
abgelegt. Beim ersten Start installiert PDF SmartForms Studio neue Pakete
automatisch in den lokalen Vorlagenbestand. Bereits installierte Versionen
werden nicht überschrieben.

Der Ordner darf keine Profile, ausgefüllten Werte oder Unterschriften enthalten.
